# Recall · AI 智能错题本 — 产品包 v1.0

> 学生错题管理 + AI 智能识别 + SM-2 间隔重复复习 + 数据看板的一体化产品。
> 单文件 Web 应用即可完整运行，无需安装任何环境；Vue3 前端与 FastAPI 后端为工程化实现。

---

## 一、快速开始（30 秒）

### 方式 A：直接打开单文件版（推荐体验）

双击打开 `01-产品应用/recall-app.html`（或拖入浏览器），**无需任何环境**，所有功能开箱即用：

- 今日首页 / 错题集 / AI 答疑 / 数据看板 / 复习计划 / 帮助
- 拍照 / 截图 / 文本 / 对话 四种录入方式
- AI 自动识别学科、知识点、解析；图片即题目
- ABCD 选择题复习 + SM-2 间隔重复排期
- 本地数据持久化（localStorage，刷新不丢失）
- PDF / Markdown 导出

> ⚠️ 注意：若数据保存失败，页面会显示黄色横幅提示——通常是因为在受限预览 iframe 中打开，请点击「在新标签页打开」或直接访问公网链接。

### 方式 B：公网在线体验

打开 `01-产品应用/公网链接.txt` 中的链接，任何人无需安装即可使用。

### 方式 C：工程化部署（Vue3 + FastAPI）

- 后端：`03-后端服务/recall-backend` → `pip install -r requirements.txt` → `python run.py`（端口 8000）
- 前端：`02-前端工程/recall-frontend` → `npm install` → `npm run dev`
- 视觉识别 Key 仅存后端 `config.py`，前端不暴露（安全）

## 五、技术要点

- **AI 三级降级**：激活 Provider 直连 → 后端代理 → 本地智能回复（算式可本地计算）
- **流式回复**：直连时 SSE 流式逐字渲染，首字 <2s
- **Markdown + LaTeX 渲染**：AI 回复的标题/粗体/列表/上下标/化学式（⇌、→、H₂ 等）自动格式化
- **对话记录**：多会话持久化，首条消息自动生成标题，支持重命名 / 删除
- **持久化**：错题、分类、复习记录、对话全部 localStorage 落盘；图片录入时自动压缩（最长边 1000px）防超限
- **安全**：`esc()` 统一 sanitize + `safeImg()` 图片 src 白名单 + 视觉 Key 后端化 + cfoot 缺失自愈
